StudyFlow Android APK project (cloud build)

Me project eka GitHub Actions use karala debug APK ekak build karanawa. Windows 7 PC eke Android Studio install karanna one naha.

1) GitHub account ekak hadanna/login wenna: https://github.com
2) New repository ekak hadanna. Name: StudyFlow-Android. Public repository ekak hadanna puluwan.
3) Me ZIP eka extract karala athule files/folders tika repository root ekata upload karanna. .github folder ekath upload wenna one.
4) GitHub repository eke Actions tab ekata yanna. Build StudyFlow APK workflow eka pennanawa.
5) Workflow eka auto run unoth hari; nathnam Run workflow button eka press karanna.
6) Run eka green tick unama run eka open karala page eke pahala Artifacts section eken StudyFlow-debug-APK download karanna.
7) ZIP eka extract karala app-debug.apk phone ekata copy karala install karanna. Phone eka install confirmation ekak pennuwoth APK eka oyama build karapu project eke output eka kiyala check karala witharak proceed karanna.

Important:
- Meeka debug APK ekak. Google Play release APK ekak nemei.
- Github account eka hadanna/sign in wenna one; password/API key wage secrets kisima kenekta denna epa.
- APK eka me environment eke build/test kara naha; cloud build pass wenawada workflow result eken confirm karanna.
- App data device eke local storage eke save wenawa. Backup export feature eka use karanna.
